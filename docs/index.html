Native NAS Access

Built for daily UNAS workflows

UNAS Access is designed for quick file browsing, media previews, transfers, and system visibility without mounting SMB or NFS over unreliable remote networks.

Files

Browse folders, preview common files, manage links, and keep routine NAS work close to the native platform UI.

Remote Access

Sign in with your UniFi account to reach your NAS through official UniFi remote access infrastructure.

Transfers

Track uploads, downloads, and background work with a focused transfer view.

Integrations

Configure Files app integration and photo/video backup behavior from one place.

Privacy

No app backend

The app does not collect analytics or send your files, credentials, or usage data to servers operated by us. Network communication is between the local app, your UniFi hardware, and official UniFi services when you choose remote sign-in.

Support

Public issue tracker

Use GitHub Issues for bug reports, feature requests, and compatibility notes. Do not post passwords, API keys, cookies, or private access tokens in public issues.
